# ChatGPT 提示词模板

## 模板选择规则（先做，再生图）

不要默认使用账号模板库的第 1 张图。每张源图都要先判断内容版式，再从该账号的多张模板图里选最匹配的一张。

## 分类自检 checklist（生图前必填）

每张源图生图前必须先输出 (role, template) 决策。判定钩子：

- 整机产品图占比 ≥ 30% 且只讲一个型号（不属于攻略系列）→ `product`
- 多列 × 多行规格表 → `comparison`
- 选购攻略章节（即使章节里嵌大产品图）→ `detail`
- 大标题 + 4 张预览缩略 → `cover`

⚠️ **边界规则**：选购攻略系列笔记（如"一/二/三/四/五/六"分章节）里某些章节配了大产品图，也全部归类 `detail`。整体叙事结构 > 单页局部视觉密度。不要按局部视觉拆类。

⚠️ **风格锁死（写进 codex prompt）**：codex 接到 detail 任务后，即使源图里有大产品图也不能漂移成 product 风格。把大产品图缩小嵌到 detail 模板的小图位，不要让产品图成为视觉中心。

⚠️ **封面双重锁定**：cover 模板可能不仅锁视觉风格，还锁**内容文案套式**——账号已经设计好的固定文案，每次只换品类名一个槽位（如"三天三夜研究 / 堪比论文 / {品类}"）。判断信号：模板文案带账号人设语气（"三天三夜研究"等），跟具体笔记主题强解耦。这种封面**禁止**把 dbs-xhs-title 出的爆款标题塞进封面，必须照抄固定文案+替换品类名。爆款标题留在 Base 的"新标题"字段、发笔记时用，跟封面图分离。detail/product/comparison **不**适用此规则。

## 输出尺寸规则（重要）

小红书最终交付图统一为 **3:4 竖图**，优先从生图阶段生成原生 3:4（如 `1080×1440` / `1086×1448`）。
- 不要把 `1024×1536` / `2:3` 当作小红书标准竖图交付。
- 不要输出 `9:16` 长图，除非用户明确指定。
- 如果内置生图工具只能产出其它比例，先保留中间图，再用 `scripts/normalize-3x4.ps1` 补边/缩放成 `1080×1440`。
- 归一化优先“补边保内容”，不要直接裁掉标题、产品图或底部卡片。

常见匹配：
- 封面/总览图：大标题 + 产品主体 + 卖点/模块预览 → 选"总览封面"模板
- 参数对比表：多列产品 + 多行参数 → 选"参数对比表"模板
- 单品说明：单个产品 + 卖点/参数拆解 → 选"单品说明"模板
- 攻略长图/知识卡片：选结构最接近的攻略/说明模板；没有时优先总览封面或单品说明，不要默认参数表

## 生成顺序规则（重要）

如果一组源图里第 1 张是封面/总览图，且封面里包含后续详情图的预览卡片，则**不能先生成第 1 张**。

正确顺序：
1. 先生成后续详情图（如 `source_2..N`），每张都锁定原图排版，只迁移风格。
2. 再生成第 1 张总览图，把已经生成好的详情图作为底部/侧边预览卡片的内容参考。
3. 总览图只换视觉风格，不要凭空改写后续卡片内容，也不要重新发明详情页。

## 排版锁定规则（重要）

详情页默认不是重排设计，而是**锁原图排版，只换风格**：
- 保留源图的标题位置、产品图位置、模块数量、模块顺序、内容层级和大致留白。
- 不把封面图改成参数表，不把单页说明改成三列总览，不跨类型重排。
- 只迁移模板的配色、字体质感、边框、卡片样式、强调色、圆角、阴影和整体美观度。
- 只有用户明确要求“重做排版”时，才允许大幅重排。

## 封面/总览图规则（重要）

封面/总览图不要默认锁源图排版，而是**主要锁定封面模板排版**：
- 封面模板的标题区、卖点区、产品区、预览卡片区是主结构，优先保留。
- 源图只提供主题、产品、核心卖点方向和后续详情图关系，不继承源图的旧封面风格。
- 预览卡片必须来自已经生成好的详情图，卡片内容和顺序必须与详情图一致。
- 不要凭空新增模板里没有的栏目、底部导航、标签、说明条、装饰文字或卖点。
- 只在模板已有槽位填入特定内容；没有槽位就不要加。

## 固定提示词（复制到 ChatGPT 输入框）

请重新绘制一张新图：锁定第二张图的原始排版、模块位置、内容层级和大致构图，只把视觉风格换成第一张图的设计感。保留第二张图的主题、产品、卖点、关键信息和模块顺序；只参考第一张图的配色、字体质感、边框、卡片样式、强调色、圆角、阴影和整体美观度。请直接输出生成的图片，不要文字分析。

## 封面/总览图固定提示词

请重新绘制一张封面总览图：以第一张图作为主要排版模板，保留第一张图的标题区、卖点勾选区、产品展示区和预览卡片区。第二张图只提供本次主题、产品和核心内容方向；不要继承第二张图的旧封面风格。预览卡片必须引用已经生成好的详情图，内容和顺序要与详情图一致。不要在模板没有预留的位置新增栏目、标签、导航条、说明条、装饰文字或额外卖点。只在模板已有槽位填入特定内容。请直接输出生成的图片，不要文字分析。

## 上传顺序（重要）

1. 先上传已选中的模板图（对应"第一张图"）
2. 再上传源图（对应"第二张图"）
3. 发送提示词

## 每张原图一个新对话

- 不要在同一个对话里连续处理多张（上下文会污染、风格漂移）
- 每处理完一张，点 "New chat" 开新对话再处理下一张

## 失败诊断关键词（DOM 文本匹配）

出现以下文字任一条 → 视为本张失败或配额用完：

**配额用完（立即中止整个任务）**：
- "You've reached your limit for image generation"
- "已达到图像生成的使用上限" / "图像生成的使用上限"
- "Too many requests" / "请求过多"
- "rate limit" / "限额"
- "Image generation is currently unavailable"

**一般失败（重试 2 次）**：
- "There was an error generating the image"
- "生成图像时出错"
- "Something went wrong" / "出现错误"
- 超时（180 秒无任何信号）
